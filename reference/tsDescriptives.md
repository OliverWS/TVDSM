# Compute Time Series Descriptive Statistics

Compute Time Series Descriptive Statistics

## Usage

``` r
tsDescriptives(data, fs = 32)
```

## Arguments

- data:

  Numeric vector of data.

- fs:

  Sample rate (default is 32).

## Value

A list of descriptive statistics including mean, se, sd, var, trend,
min, max, slope, slopeRatio, range and autocorrelation.
