# Plot Topography Density

Plot Topography Density

## Usage

``` r
topography(x, y, xlab = "X", ylab = "Y")
```

## Arguments

- x:

  Numeric vector for x-axis.

- y:

  Numeric vector for y-axis.

- xlab:

  Label for x-axis.

- ylab:

  Label for y-axis.

## Value

A ggplot object showing 2D density plot.
