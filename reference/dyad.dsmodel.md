# Build Dyadic Model

Build Dyadic Model

## Usage

``` r
dyad.dsmodel(p1, p2, type = 2, step = 0.25, measure = "EDA")
```

## Arguments

- p1:

  Data for participant 1.

- p2:

  Data for participant 2.

- type:

  Model type (default 2).

- step:

  Step size (default 0.25).

- measure:

  Column name for measurement (default "EDA").

## Value

A model object.
