# Fit Dyadic Model using SEM

Fit Dyadic Model using SEM

## Usage

``` r
dsmodel.sem(d, type = 2, step = 0.25, p.value = 0.01, verbose = T)
```

## Arguments

- d:

  Data frame containing dyad data.

- type:

  Model type (default 2).

- step:

  Step size (default 0.25).

- p.value:

  P-value threshold (default 0.01).

- verbose:

  Logical indicating verbose output (default TRUE).

## Value

A SEM model object.
