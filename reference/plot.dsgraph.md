# Create Plot for Dyadic State Space Graph

Create Plot for Dyadic State Space Graph

## Usage

``` r
# S3 method for class 'dsgraph'
plot(s, title = "State Space Plot", xlabel = "X Data", ylabel = "Y Data")
```

## Arguments

- s:

  A dyadic statespace model object.

- title:

  Plot title.

- xlabel:

  Label for x-axis.

- ylabel:

  Label for y-axis.

## Value

A ggplot object.
