# Save data for graphing from TVDSM analysis

Exports the R-squared summary metrics of the TVDSM analysis to CSV
files.

## Usage

``` r
saveDataForGraphing(mdls, xfname = "Dyad_X.csv", yfname = "Dyad_X.csv")
```

## Arguments

- mdls:

  A list containing TVDSM model outputs and summary data.

- xfname:

  Filename for saving participant X's R-squared data.

- yfname:

  Filename for saving participant Y's R-squared data.

## Value

None.
