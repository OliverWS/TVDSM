# Describe dyad interdependence

Computes descriptive statistics for dyad interdependence metrics based
on TVDSM outputs.

## Usage

``` r
describeDyad(mdls, xname = "Participant 1", yname = "Participant 2")
```

## Arguments

- mdls:

  A list of TVDSM model outputs.

- xname:

  Friendly name for participant 1.

- yname:

  Friendly name for participant 2.

## Value

A summary of interdependence measures.
